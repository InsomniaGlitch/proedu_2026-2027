# Ссылки на учебник в источниках

Вместо голого названия главы Tutor выводит ссылку, которая открывает PDF учебника сразу на нужной странице:

```
Источники:
- [1.1. Экологическая устойчивость и экологические кризисы](https://elar.urfu.ru/bitstream/10995/150343/1/978-5-7996-4169-6_2026.pdf#page=14) — учебник, с. 12
```

Фронтенд уже рендерит Markdown-ссылки (`target="_blank"`), поэтому менять его не нужно.

## Откуда берутся страницы

Учебник: Орешкина Т. А. и др. «Устойчивое развитие: системный подход», УрФУ, 2026
([карточка](https://elar.urfu.ru/handle/10995/150343)).

- В PDF первые две страницы - обложка: **печатная страница N = страница N + 2 в PDF** (7-я страница PDF = 5-я печатная). Смещение — `PDF_PAGE_OFFSET` в `sources_formatter.py`.
- Ссылка `...pdf#page=N` использует номер **страницы PDF**, а в подписи показывается **печатный** номер — тот, что студент видит на странице книги.
- Соответствие «документ → печатная страница» хранится в словаре `TEXTBOOK_PAGES` внутри `custom_components/sources_formatter.py` (между маркерами `BEGIN/END TEXTBOOK_PAGES`). Ключ — номер раздела (`"1.1"`, `"прил.2"`), а не полное название, поэтому исправление опечатки в `documents.filename` не ломает ссылку.
- Для документов, которых нет в словаре (например, «0.1. O курсе», которого, вероятно, нет в самой книге), выводится просто название без ссылки.

## Как заполнить страницы

Словарь заполняет скрипт — он находит заголовки глав в PDF, поэтому номера не нужно вводить вручную:

```bash
pip install pypdf
# скачайте PDF учебника и запустите из корня репозитория:
python scripts/build_textbook_toc.py 978-5-7996-4169-6_2026.pdf --dry-run   # проверить отчёт
python scripts/build_textbook_toc.py 978-5-7996-4169-6_2026.pdf --sync-flow # записать + обновить Flow
```

Скрипт пропускает страницы оглавления, ищет заголовок каждого документа (до трёх строк подряд, регистр и пунктуация не важны), при неудаче пробует закладки PDF и печатает отчёт «документ → страница PDF → печатная страница». **Просмотрите отчёт**: если какой-то документ найден не там — поправьте значение в `TEXTBOOK_PAGES` вручную. Если обложка другого размера — `--offset N`.

Если в `documents` появятся новые документы, добавьте их названия в `DEFAULT_TITLES` в скрипте (или передайте `--titles-file`) и запустите скрипт снова.

## Обновление Flow

Код компонента хранится и в `flow/tutor-flow.json`. Флаг `--sync-flow` (или `--sync-flow-only`, если PDF не нужен) копирует текущий `sources_formatter.py` в Flow. После этого переимпортируйте Flow в Langflow и обновите `TUTOR_FLOW_ID` (см. README), либо вставьте код через кнопку Code на узле Sources Formatter.

## Ограничения

- Ссылка ведёт на **главу**, а не на фрагмент, по которому отвечала модель: в базе нет номеров страниц у чанков.
- Открытие на нужной странице зависит от PDF-просмотрщика (`#page=` поддерживают браузеры и Acrobat).
- Если УрФУ перенесёт файл, поменяйте `TEXTBOOK_URL`.
- Следующий шаг при необходимости: сопоставить каждый чанк со страницей PDF при векторизации (`dcv`) и хранить `page` в `document_chunks` — тогда ссылка будет вести на конкретное место.
