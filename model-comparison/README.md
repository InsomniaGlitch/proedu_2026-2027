## Условия

- Только роль Tutor, 16 вопросов в 7 категориях, один прогон, температура 0.1.
- Одинаковые системный промпт и фрагменты базы знаний для всех моделей (имитация RAG).
- **Фрагменты и кейс 2 — модельные**, написаны по общеизвестным источникам: материалов курса пока нет. После их получения фрагменты в `questions_pilot.json` заменяются реальными.
- Оценки: поведение и опора на источники — вручную (Claude, по рубрике), ссылки, язык, скорость — автоматически. Слепая перепроверка 20% человеком: исходная каппа Коэна 0.09 (поведение) и 0.31 (источники), расхождения согласованы.
- Бесплатные модели OpenRouter: Gemma 4 31B (429) и Inkling (403) были недоступны и заменены; Xing4.0 ответила на 12 из 16 из-за лимитов провайдера.

## Запуск

Нужен Python 3 и `requests`. Ключи — в файле `.env` рядом со скриптами (в git не попадает):

```
GIGACHAT_AUTH_KEY=...
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_INSECURE=1
OPENROUTER_API_KEY=...
```

```bash
python3 check_gigachat.py   # проверка ключа GigaChat и список доступных моделей
python3 run_pilot.py        # прогон; повторный запуск догружает только неудачные ответы
python3 make_report.py      # сводка
```
