# DCV — очистка и векторизация данных

Подготавливает данные, извлеченные из arXiv и BiblioClub, выполняет их векторизацию с помощью модели `bge-m3` и сохраняет результат в базу данных.

## Установка

1. Установите Python версии 3.14 или выше.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Быстрый старт

1. Заполните поля конфигурации в файле `config.json` в соответствии с вашими задачами.
2. Откройте терминал в директории, содержащей файл `main.py`, и выполните команду:

```bash
python main.py
```
